# Stroke code pathway (hospital)
(Starter note. Verify against your local stroke protocol.)

1. Pre-hospital: recognise with BE-FAST, record last-known-well, check glucose, alert the stroke centre.
2. On arrival: stroke code activated, airway-breathing-circulation, IV access, bloods, ECG.
3. Imaging: non-contrast CT head, add CT angiography for large-vessel occlusion. Target within about 20 to 25 minutes.
4. Treatment: IV thrombolysis within 4.5 hours of onset if no contraindication (door-to-needle 60 minutes or less). Thrombectomy for large-vessel occlusion, up to 24 hours in selected patients.
5. Blood pressure: below 185/110 before lysis. Without lysis, treat only above 220/120. Avoid sudden large drops.
6. Haemorrhage on CT: neurosurgical review, reverse anticoagulants, control blood pressure.
7. Swallow screen before any food, drink or oral medicine. Admit to a stroke unit.
